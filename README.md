## プリフロップ GTO トレーナー (6-max対応)

ポーカー（テキサスホールデム）の初心者向けに作成した、プリフロップでの最適な戦術（GTO）をクイズ形式で学べるWEBアプリケーションです。

## 🌐 アプリケーションURL
実際に遊べるURL（GitHub Pages）:　**https://kn-jpn.github.io/Preflop-GTO-Trainer/**

## ⭐ 開発の背景・目的
ポーカーの勝率に最も直結するプリフロップの習得を、移動時間などの隙間時間にスマホ一台でサクサク練習できるツールが欲しかったため自作しました。

## 👀 こだわったポイント
1. **スマホ向けのUI設計**
   スマホの画面でも片手で押し間違えることなくサクサク解答できるよう、ボタンサイズや配置にこだわりました。
2. **データ駆動型による拡張性の高い設計**
   169通りの手札と全ポジション（UTG, HJ, CO, BTN, SB, BB）の膨大な条件分岐を、すべてコード内に直接書くのではなく、判定ロジックとGTOの辞書データを分けた設計にしました。
   これにより、今後機能を追加したい際に簡単に対応できる高い拡張性を持たせています。

## 🛠️ 開発環境
**UI実装**: HTML5, CSS3, JavaScript (Vanilla JS)
　　**公開環境**: GitHub Pages
